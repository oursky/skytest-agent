# Linear Skills

Skills for creating and managing Linear bug reports, and converting them into SkyTest regression tests.

| Skill | Command | Description |
|-------|---------|-------------|
| [linear-bug-report](./linear-bug-report/SKILL.md) | `/linear-bug-report` | Create structured bug reports in Linear from screenshots and brief descriptions |
| [linear-bug-revise](./linear-bug-revise/SKILL.md) | `/linear-bug-revise` | Revise an existing Linear bug report to follow the team's standard format |
| [linear-bug-to-skytest](./linear-bug-to-skytest/SKILL.md) | `/linear-bug-to-skytest` | Convert a Linear bug report into SkyTest regression test cases |
